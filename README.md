# 🌿 La Serre

Tableau de bord personnel de pilotage des projets, horizons trimestriels et jalons mensuels.

## Principes

- Une couleur et une icône propres à chaque projet.
- Les objectifs appartiennent à La Serre ; les tâches concrètes appartiennent à Todum.
- Un mois cible n'est pas une deadline ferme.
- Les semaines sont facultatives et peuvent accueillir un même jalon sans duplication.
- Interface accessible, aérée et responsive.

## Installation

Le schéma initial est prévu dans `supabase/001_schema.sql`. **Ne pas l'exécuter avant vérification de la configuration Supabase Auth du projet Hub writing.** Il crée uniquement des objets préfixés `serre_`.

Aucune clé secrète Supabase ne doit être publiée dans ce dépôt.
